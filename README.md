# 心语台 EmpathyDesk

心语台是一套辅助美妆电商人工客服的 AI 智能服务工具 Demo。它模拟了“千牛客服工作台”中的关键交互，不需要真实店铺账号即可演示。

## 功能

- 智能接待辅助面板：用户全景、服务轨迹、意图识别、情绪判断、共情回复建议
- 模拟客服聊天窗口：会话切换、快捷回复、采纳 AI 建议
- 风险预警跟踪看板：风险趋势、预警筛选、风险详情、闭环操作
- 内置 3 个美妆客服场景：敏感肌泛红、订单物流延迟、重复退款风险

## 运行方式

直接打开 `index.html`，或使用任意静态服务器：

```bash
python -m http.server 8080
```

访问 `http://localhost:8080/`。

## 技术说明

当前 Demo 使用纯 HTML、CSS 和 JavaScript，数据为前端模拟数据。正式版本可在此基础上接入：

- 千牛会话上下文
- 订单、工单、聊天等多源业务数据
- 开源大模型 Agent 链路
- RAG 商品与售后知识库
- 风险预警与工单闭环服务
